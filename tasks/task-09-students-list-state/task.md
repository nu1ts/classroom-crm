# Статусы, сортировка и сохранение состояния списка учеников

## Сайт

«Кабинет классного руководителя» — одностраничное приложение для классного
руководителя 7Б класса. Раздел «Ученики» показывает список класса с колонками
«Ученик», «Статус», «Средний балл», «Пропуски», «Родитель для связи» и
«Действия». В списке доступны поиск по фамилии, фильтр «С пропусками»,
сортировка по среднему баллу и пропускам, пагинация по 10 учеников и сводка
ученика.

Все данные хранятся в `localStorage` браузера. Статус ученика и попадание
в зону риска — разные признаки: статус показывает только состояние учётной
записи, а риск отмечается отдельным бейджем рядом с ФИО. Поиск, фильтр,
выбранная сортировка и страница должны сохраняться при переходах по страницам
и при закрытии сводки ученика.

## Начальные данные

- в 7Б классе 28 учеников; размер страницы — 10 учеников, всего три страницы;
- у всех учеников статус «Активен»; бейдж «В зоне риска» стоит у пяти учеников:
  Сидорова Никиты, Морозова Артёма, Петровой Анны, Волковой Софии и
  Котова Максима;
- поиск «ов» находит 12 учеников; при сортировке по пропускам по убыванию
  первая страница начинается с Сидорова Никиты, а на второй странице остаются
  Романов Илья и Александров Егор;
- сортировка по среднему баллу по возрастанию начинается с Сидорова Никиты
  (3,1) и Котова Максима (3,3); по убыванию — с Романова Ильи (5,0) и
  Александрова Егора (4,8);
- фильтр «С пропусками» и поиск «александров» вместе не находят ни одного
  ученика: список пуст, счётчик показывает «из 0», доступна кнопка сброса;
- при поиске «ов» и сортировке по пропускам по убыванию закрытие сводки
  Сидорова Никиты не сбрасывает поиск, сортировку и страницу;
- демонстрационная база создаётся заново после очистки `localStorage`.

## Что проверить

1. `test_ov_05_status_and_risk_badge` — во всех 28 строках колонка «Статус»
   содержит только «Активен»; бейдж «В зоне риска» стоит ровно у пяти учеников
   из начальных данных и не попадает в колонку «Статус».
2. `test_ov_07_empty_search_with_filter` — при включённом фильтре «С пропусками»
   поиск «александров» оставляет пустой список с сообщением «Ничего не найдено»,
   счётчиком «из 0» и кнопкой сброса; после сброса снова видны 28 учеников.
3. `test_ov_09_pagination_keeps_sort` — после поиска «ов» и сортировки по
   пропускам по убыванию вторая страница содержит Романова Илью и
   Александрова Егора, а возврат на первую страницу сохраняет поиск и
   сортировку: сверху остаётся Сидоров Никита.
4. `test_ov_10_sort_by_average` — по возрастанию среднего балла первые строки —
   Сидоров Никита (3,1) и Котов Максим (3,3); после переключения на убывание —
   Романов Илья (5,0) и Александров Егор (4,8).
5. `test_ov_11_summary_close_keeps_state` — при поиске «ов» и сортировке по
   пропускам по убыванию открытие и закрытие сводки Сидорова Никиты сохраняет
   поиск, сортировку и первую страницу списка.
