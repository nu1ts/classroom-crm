# Объявления: аудитория и счётчики

## Сайт

«Кабинет классного руководителя» — одностраничное приложение школы. Классный
руководитель 7Б публикует объявления для родителей и учеников. Родители и
ученики просматривают одну и ту же ленту только для чтения; счётчик прочтений
ведётся по семьям, то есть по ученикам класса. Все данные хранятся в
`localStorage` и восстанавливаются после его очистки. Демонстрационная дата —
28.10.2024.

## Начальные данные

- опубликованы два объявления для 7Б: «Родительское собрание 31 октября» и
  «Каникулы с 28 октября по 5 ноября»;
- у объявления о собрании счётчик равен «прочитали 19 из 28»;
- Петров С. В. и Петрова Анна относятся к одной семье: прочтение ими одного
  объявления должно засчитываться только один раз;
- ближайшее собрание можно использовать для перехода к форме публикации:
  заголовок формы заполняется темой собрания, но связь между объявлением и
  собранием не создаётся;
- классный руководитель может создавать и удалять объявления, родитель и
  ученик видят ленту только для чтения.

## Что проверить

1. `test_an_06_parent_student_see` — родитель видит объявление о собрании,
   после первого полного открытия счётчик меняется с 19 до 20 из 28. Ученица
   той же семьи видит тот же текст, дату, адресата и счётчик, но её открытие
   не увеличивает его повторно. Классный руководитель также видит значение
   20 из 28.
2. `test_an_08_publish_from_meeting` — кнопка «Опубликовать объявление» в
   карточке ближайшего собрания открывает форму с заголовком по теме собрания.
   После заполнения текста новое объявление находится первым в ленте 7Б, а в
   его данных и в карточке собрания нет признака связи между сущностями.
3. `test_an_09_read_counter` — при подготовленном значении 27 из 28 первое
   открытие последней семьёй доводит счётчик до 28 из 28. Повторные открытия
   родителем и учеником этой семьи не меняют значение и не позволяют превысить
   знаменатель.
4. `test_an_10_empty_state` — после подтверждённого удаления всех объявлений
   классный руководитель видит сообщение «Объявлений пока нет» и кнопку
   «Новое объявление». У родителя и ученика также отображается пустой список
   без ошибки отрисовки.
