# Успеваемость и зона риска

## Сайт

«Кабинет классного руководителя» — одностраничное приложение для классного
руководителя 7Б класса. В разделе «Аналитика» формируется отчёт по выбранному
периоду: средние баллы по предметам, список учеников в зоне риска и сводная
информация о пропусках.

Данные приложения хранятся в `localStorage`. После очистки хранилища
демонстрационная база создаётся заново.

## Данные для входа

| Роль | Логин | Пароль |
| --- | --- | --- |
| Классный руководитель 7Б | `smirnova@school.ru` | `Test#2024` |

## Начальные данные

- по умолчанию выбран период «I четверть 2024»;
- порог внимания по среднему баллу составляет 3,5;
- в зоне риска есть Сидоров Никита и Морозов Артём по пропускам, а Котов Максим — по успеваемости;
- у Сидорова Никиты одновременно есть основания по пропускам и среднему баллу.

## Что проверить

1. `test_bp_11_absences_breakdown` — подтверждённый пропуск выводится в
   сводном списке один раз и сохраняет статус «Подтверждён».
2. `test_bp_12_subject_average_threshold` — в отчёте по предметам явно
   указан порог зоны риска 3,5.
3. `test_bp_13_risk_by_absences` — в зоне риска отображаются Сидоров Никита
   и Морозов Артём; причиной для них указаны пропуски.
4. `test_bp_14_risk_by_average` — Котов Максим попадает в зону риска по
   среднему баллу независимо от доли пропусков.
5. `test_bp_15_risk_both_reasons` — Сидоров Никита показан одной карточкой,
   содержащей причины и по пропускам, и по среднему баллу.
