# Неподтверждённые пропуски

## Назначение

В «Кабинете классного руководителя» неподтверждённая отметка отсутствия обозначается «Н (без)». Классный руководитель 7Б контролирует её на страницах `/overview/`, `/attendance/` и `/journal/`. Предметник может фиксировать отсутствие, но не вправе подтверждать причину. После подтверждения уважительной причины запись получает код «УП», основание и автора подтверждения; после отказа она остаётся неуважительным пропуском и учитывается в зоне риска.

Демонстрационная дата — 28.10.2024. Очистка `localStorage` восстанавливает исходные данные.

## Учётные записи

| Роль | Логин | Пароль |
| --- | --- | --- |
| Классный руководитель 7Б | `smirnova@school.ru` | `Test#2024` |
| Учитель математики | `kozlov@school.ru` | `Test#2024` |

## Исходные данные

- В I четверти 2024/2025 у Петровой Анны Сергеевны есть неподтверждённая отметка на уроке математики 24.10.2024.
- Урок 7Б имеет идентификатор `lsn-39`, ученица — `st-23`.
- На обзоре есть предупреждение о неподтверждённых пропусках и ссылка в посещаемость для ученицы.

## Проверяемые сценарии

### `test_bp_06_unconfirmed_list_link`

Войти классным руководителем и открыть `/overview/`. Ссылка из предупреждения должна вести в `/attendance/` с `filter=unconfirmed` и идентификатором Петровой Анны. После перехода в таблице посещаемости должна быть выделена строка этой ученицы, а в ней — отметка «Н (без)».

### `test_bp_07_no_warning_without_unconfirmed`

Тест легитимно переводит все неподтверждённые отсутствия в уважительные в `localStorage`. На посещаемости за неделю `w8` предупреждение о неподтверждённых пропусках не должно отображаться. На `/overview/` карточка «Без подтверждения» должна показывать 0.

### `test_bp_08_confirm_author`

Войти классным руководителем. Тест вызывает разрешённый API подтверждения для исходной записи Петровой, передавая основание «Болезнь» и документ «Справка № 142 от 25.10.2024». Операция должна завершиться успешно: запись получает код «УП», документ, автора «Смирнова М. В.», а число записей со статусом `unconfirmed` уменьшается.

### `test_bp_09_confirmed_not_editable`

Войти классным руководителем, открыть запись Петровой в журнале и подтвердить её как уважительную через форму. Затем войти учителем математики и попытаться снять отсутствие через API журнала. Операция должна быть отклонена с сообщением о подтверждённой отметке; в данных сохраняются отсутствие и статус `excused`.

### `test_bp_10_refusal_keeps_absence`

Войти классным руководителем и отказать в подтверждении исходной отметки. Запись должна сохраниться со статусом `unexcused`, кодом «Н» и без автора подтверждения. В сводке ученицы в списке внимания число пропусков не должно уменьшиться.

### `test_bp_34_subject_teacher_api_denied`

Войти учителем математики и вызвать API подтверждения для неподтверждённой отметки Петровой. API должен вернуть отказ с сообщением, что действие недоступно, и не изменить статус записи и автора подтверждения.
