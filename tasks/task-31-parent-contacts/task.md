# Контакты с родителями

## Назначение

Классный руководитель 7Б фиксирует внутренние контакты с родителями и педагогические заметки об учениках. Контакт связывается одновременно с родителем и учеником, имеет канал, итог разговора, дату и при необходимости дату повторного контакта. Педагогическая заметка — отдельный тип записи и не должна попадать в историю общения с родителями. Внешним ролям внутренние заметки недоступны.

Демонстрационная дата — 28.10.2024. Очистка `localStorage` восстанавливает исходные данные.

## Маршруты и данные сценариев

Сводка ученика открывается на `/student/?id=<идентификатор>&period=q1_2024`, сводка родителя — на `/parent/?id=<идентификатор>`. В сценариях используются Сидоров Никита Артёмович (`st-14`) и его родитель (`pr-27`). Прямое обращение к `crmApi` допустимо только в сценариях, которые проверяют доменные правила сохранения контакта без привязки к форме.

## Проверяемые сценарии

### `test_bp_25_contact_linked_to_parent`

Войти классным руководителем и через разрешённый API сохранить для `pr-27` и `st-14` телефонный контакт с итогом «Обсудили пропуски, справку принесут после каникул», достигнутой договорённостью, датой 28.10.2024 и временем 10:00. Результат сохранения должен содержать оба идентификатора.

В сводке Сидорова и в сводке его родителя должна появиться запись с этим итогом. В истории родителя также должны быть автор «Смирнова М. В.» и канал «Звонок».

### `test_bp_26_contact_summary_required`

Войти классным руководителем и запомнить количество контактов. Через API попытаться сохранить контакт без итога, затем без канала связи. Обе операции должны вернуть отказ: для первой — сообщение об итоге, для второй — о канале. После двух попыток количество записей `parentContacts` не меняется.

### `test_bp_27_note_not_contact`

Войти классным руководителем, добавить для Сидорова заметку «Стал замкнут, нужна беседа с психологом» и сравнить количество контактов до и после. Заметка должна появиться среди заметок ученика, но не увеличивать историю контактов и не отображаться в её блоке.

### `test_bp_28_agreement_reached`

Войти классным руководителем и сохранить для Сидорова контакт с достигнутой договорённостью, передав также дату повторного контакта. Сохранённый контакт должен иметь `agreementReached = true`, а дата повторного контакта должна быть очищена.

Далее тест легитимно готовит для Сидорова запись о завершённой работе и контакт с достигнутой договорённостью. На `/overview/` карточка Сидорова должна показывать «Обработан» и не содержать указания на повторный контакт.

### `test_bp_29_repeat_contact_reminder`

Войти классным руководителем и сохранить через API контакт для Сидорова без достигнутой договорённости, с итогом «Нужно повторно уточнить справку» и датой повторного контакта 28.10.2024. Эта дата должна сохраниться у созданного контакта.

На `/overview/` карточка Сидорова не должна иметь статус «Обработан»: назначенное напоминание означает, что работа с учеником продолжается.

### `test_bp_30_notes_private`

Войти классным руководителем и добавить Петровой Анне внутреннюю заметку «Внутренняя заметка классного руководителя». Затем войти родителем и открыть сводку Петровой, а после войти ученицей и открыть `/grades/`. Ни в одной из внешних страниц не должны быть видны текст заметки и заголовок «Заметки классного руководителя». При этом страница оценок ученицы должна открываться.
