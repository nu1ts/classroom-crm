# Аналитика: отчёты и права

## Сайт

«Кабинет классного руководителя» — одностраничное приложение для классного
руководителя 7Б класса. В разделе «Аналитика» классный руководитель строит
отчёт за период: средний балл класса, посещаемость, счётчик неподтверждённых
пропусков, средние баллы по предметам и зона риска. Отчёт строится по журналу
заново при каждом запросе — в базе он не хранится.

Раздел «Аналитика» показывает классному руководителю данные только его класса.
Учитель-предметник видит аналитику только по своей нагрузке: математику в 7Б и
8А, алгебру в 9В; запрос класса вне нагрузки запрещён, а запрос чужого предмета
не раскрывает его оценки и показатели. Родитель в разделе «Ребёнок» видит
показатели только своего ребёнка, а не всего класса.

Все данные хранятся в `localStorage` браузера. Демонстрационная база создаётся
заново после очистки `localStorage`.

- за I четверть в журнале 1120 отметок о посещаемости, 72 пропуска, посещаемость

- у Петровой Анны средний балл 4,50, по математике — 3,20;
- подтверждение пропуска по справке убирает его из счётчика неподтверждённых.

## Что проверить

1. `test_anl_14_unconfirmed_counter` — счётчик неподтверждённых пропусков в
   отчёте считает только пропуски со статусом «Н (без)»: пока Петрова Анна не
   подтвердила свой пропуск за 24.10.2024, в счётчике 4 неподтверждённых
   пропуска, а после подтверждения остаётся 3.
2. `test_anl_15_report_not_cached` — отчёт строится по актуальным данным
   журнала: пока все отметки о посещаемости выставлены, посещаемость класса
   93,6 %, а после того как одна из них меняется на пропуск, в новом отчёте
   93,5 %.
3. `test_anl_16_teacher_own_class_only` — классный руководитель 7Б работает
   только со своим классом: аналитика его класса открывается, а при запросе
   другого класса показывается сообщение «Доступ ограничен» и отчёт не
   строится.
4. `test_anl_17_subject_teacher_subjects` — учитель-предметник открывает
   аналитику только по нагрузке: математику в 7Б и 8А, алгебру в 9В. По предмету
   без нагрузки выводится «Нет данных по выбранному предмету» без чужих оценок,
   а класс вне нагрузки показывает «Доступ ограничен».
5. `test_anl_18_parent_child_metrics` — родитель видит показатели своего
   ребёнка: у Петровой Анны средний балл 4,50 и математика 3,20, а не
   средние показатели класса.
