# Навигация по ролям

## Назначение

Настройте боковую навигацию «Кабинета классного руководителя» для каждой роли. После входа слева отображается только разрешённое основное меню. Каждый пункт меню должен открывать соответствующий раздел. Ссылка на профиль и выход из системы расположены отдельно и не считаются пунктами основного меню.

Приложение одностраничное, демонстрационные данные и сессия хранятся в `localStorage`. Перед каждой проверкой очищаются `localStorage` и `sessionStorage`, затем приложение заново создаёт исходные данные. Вход для этих проверок может быть подготовлен тестом через сессию в хранилище; это нужно только для проверки состава меню и не отменяет требований к настоящей форме входа.

1. `test_rm_01_admin_navigation` — для администратора основное меню содержит ровно «Учётные записи», «Учителя», «Справочники», «Нагрузка», «Учебный год». Переход по каждому из пяти пунктов открывает его раздел. В меню отсутствуют «Журнал», «Ученики», «Собрания» и «Аналитика».
2. `test_rm_02_teacher_navigation` — для классного руководителя меню содержит ровно девять пунктов: «Обзор класса», «Ученики», «Журнал», «Посещаемость», «Расписание», «Родители», «Собрания», «Объявления», «Аналитика». Каждый пункт открывается. «Учётные записи», «Справочники» и «Нагрузка» отсутствуют.
3. `test_rm_03_subject_teacher_navigation` — для учителя-предметника меню содержит ровно «Мои классы», «Посещаемость», «Расписание», «Аналитика»; все эти разделы открываются. Пунктов «Родители», «Собрания» и «Объявления» нет.
4. `test_rm_04_parent_navigation` — для родителя меню состоит ровно из «Ребёнок», «Расписание», «Объявления», и каждый пункт открывается. Отсутствуют «Журнал», «Родители», «Собрания» и «Аналитика»; нигде в открытых родительских разделах нет действий «Создать собрание» или отметки явки.
5. `test_rm_05_student_navigation` — для ученика меню состоит ровно из «Расписание», «Оценки», «Объявления», и каждый раздел открывается. Нет пунктов «Ребёнок», «Журнал», «Родители», «Собрания». В боковой панели видна пометка «Только для просмотра».
