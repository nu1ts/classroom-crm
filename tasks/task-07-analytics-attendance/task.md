# Аналитика: посещаемость

## Назначение

Реализуйте расчёт посещаемости в списке «Ученики» и отчёте «Аналитика» для классного руководителя 7Б. Знаменатель посещаемости — только уроки с выставленной отметкой посещаемости: неотмеченные занятия не считаются ни посещёнными, ни пропущенными. Подтверждённый справкой пропуск остаётся пропуском в статистике.

## Учётная запись и исходные данные

- У каждого ученика 40 отметок посещаемости; всего 1120 отметок и 72 пропуска.
- Есть ещё 2 занятия по расписанию без отметок; они не должны попасть в расчёты.
- Посещаемость класса: 1048 посещений из 1120, то есть 93,6 %; доля пропусков — 6,4 %.
- Сидоров Никита (`st-14`): 12 пропусков из 40; пропуск 22.10.2024 можно подтвердить справкой.
- Котов Максим (`st-06`): 1 пропуск из 40.

После очистки `localStorage` данные восстанавливаются.

## Правила

- В списке ученика отображаются число пропусков, число отмеченных уроков и число дней с пропусками.
- Особым оформлением выделяются только пропуски выше 20 %; 30 % у Сидорова выделяются, 2,5 % у Котова — нет.
- Посещаемость класса и недельная доля считаются по всем отметкам рассматриваемой выборки, а не как среднее индивидуальных процентов или по календарным дням.

1. `test_anl_05_student_attendance_percent` — в «Учениках» у Сидорова показаны «12 из 40» и «12 дней», показатель 30 % выделен особым оформлением. У Котова показаны «1 из 40» и «1 день», но его показатель не выделен как превышение порога.
2. `test_anl_06_unmarked_not_absent` — у Александрова показано «0 из 40», а не «0 из 42»: два занятия без отметок не входят в знаменатель.

4. `test_anl_12_weekly_absences_share` — в отчёте карточка «Нед 8» содержит 11,4 % и «16 проп.», карточка «Нед 4» — 10 % и «14 проп.».
