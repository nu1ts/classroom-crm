# Посещаемость, периоды и предметные средние в аналитике

## Сайт

«Кабинет классного руководителя» — одностраничное приложение для классного
руководителя 7Б класса. Раздел «Аналитика» строит отчёт по классу: метрики
посещаемости, средний балл класса, средние баллы по предметам, пропуски по
неделям и список учеников в зоне риска. Раздел «Ученики» показывает список
класса с колонками «Средний балл» и «Пропуски», а также позволяет открыть
сводку ученика.

Все данные хранятся в `localStorage` браузера. Отчёт не сохраняется: метрики
пересчитываются из журнала при каждом формировании и при смене периода.
Пропуски считаются только по отмеченным урокам, а не по всем урокам
расписания. Ученик без оценок за период не получает ноль — для него
показывается прочерк.

## Начальные данные

- в 7Б классе 28 учеников; в I четверти 42 урока по расписанию, из них
  отмечено 40;
- за I четверть выставлено 303 оценки с суммой 1275 баллов, средний балл
  класса — 4,2; посещаемость класса — 93,6 %, пропущено 6,4 %;
- Сидоров Никита — 12 пропусков из 40 отмеченных уроков (30,0 %);
- у Васильевой Дарьи за сентябрь нет ни одной оценки, хотя в другие месяцы
  оценки есть;
- за сентябрь в 7Б выставлено 240 оценок, посещаемость класса — 94,4 %;
  за октябрь — 63 оценки, посещаемость — 92,7 %;
- средние баллы по предметам за I четверть: математика — 3,9, русский
  язык — 4,3, физика — 4,0, история — 4,4, физкультура — 4,8; порог зоны
  риска — 3,5;
- в I четверти 8 учебных недель: неделя 1 — 2,9 % пропусков (4 пропуска),
  неделя 4 — 10 % (14 пропусков), неделя 8 — 11,4 % (16 пропусков);
- демонстрационная база создаётся заново после очистки `localStorage`.

## Что проверить

1. `test_anl_06_attendance_denominator` — у Сидорова Никиты пропуски
   считаются от 40 отмеченных уроков, а не от 42 уроков по расписанию:
   в списке и в сводке показано «12 из 40», посещаемость 70,0 %, доля
   пропусков 30,0 %.
2. `test_anl_08_student_without_grades` — в аналитике за сентябрь средний
   балл класса остаётся 4,2, а у Васильевой Дарьи в списке учеников за
   сентябрь вместо балла стоит прочерк; она не получает 0,0 и не попадает
   в зону риска по баллу.
3. `test_anl_09_period_switch_recalculates` — при переключении периода
   «I четверть» → «Октябрь» → «Сентябрь» → «I четверть» метрика
   посещаемости класса пересчитывается: 93,6 % → 92,7 % → 94,4 % → 93,6 %.
4. `test_anl_11_subject_averages` — в отчёте за I четверть средние баллы по
   предметам равны 3,9 / 4,3 / 4,0 / 4,4 / 4,8, указан порог зоны риска 3,5
   и подпись о расчёте по всем ученикам 7Б.
5. `test_anl_12_weekly_absences` — в отчёте за I четверть 8 недель, доли
   пропусков по неделям совпадают с журналом: неделя 1 — 2,9 % (4 пропуска),
   неделя 4 — 10 % (14 пропусков), неделя 8 — 11,4 % (16 пропусков); подпись
   поясняет, что доля считается от всех уроков недели.
