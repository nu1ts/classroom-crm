# Дашборд: метрики класса

## Назначение

Классный руководитель 7Б после входа работает на маршруте `/overview/`, на экране «Обзор класса 7Б». Метрики строятся по текущим данным журнала и не сохраняются как отдельный снимок. Демонстрационная дата — 28.10.2024; очистка `localStorage` восстанавливает демонстрационную базу.

На экране показаны «Посещаемость сегодня», «Средний балл класса» и «Без подтверждения». Посещаемость учитывает внесённые отметки всех уроков дня, средний балл сравнивается с прошлой неделей, а в счётчик неподтверждённых попадают только записи «Н (без)».

## Исходные данные

- Стартовый экран классного руководителя — «Обзор класса 7Б» на `/overview/`.
- Средний балл 7Б за I четверть равен 4,2; рядом указано «+0,1 к прошлой неделе».
- В I четверти есть семь неподтверждённых пропусков.
- Ссылка «К журналу →» из карточки «Без подтверждения» ведёт на `/attendance?filter=unconfirmed`.

## Проверяемые сценарии

### `test_bp_01_teacher_default_screen`

Очистить состояние, войти классным руководителем через форму входа. Должен открыться маршрут `/overview/` и экран с заголовком «Обзор класса» и указанием «7Б класс», а не первый другой пункт меню.

### `test_bp_02_dashboard_attendance`

Тест после входа легитимно подготавливает в `localStorage` отметки за один день: 55 «Был» из 56 отметок двух уроков. Открыть `/overview/`. В метрике «Посещаемость сегодня» должно быть 98,2 %, а подпись должна содержать текст «из 28 присутствуют». Расчёт обязан учитывать отметки всех уроков дня.

### `test_bp_03_dashboard_average_delta`

Открыть `/overview/` после входа. В карточке «Средний балл класса» должны быть значение 4,2, изменение +0,1 и подпись «к прошлой неделе». Сравнение с первым днём периода не соответствует заданию.

### `test_bp_04_unconfirmed_metric`

Открыть обзор после входа. В данных и в карточке «Без подтверждения» должно быть семь неподтверждённых пропусков. Ссылка «К журналу →» должна вести на раздел посещаемости с параметром `filter=unconfirmed`.

### `test_bp_05_metrics_recalculated`

На открытом обзоре убедиться, что есть неподтверждённый пропуск. Затем тест легитимно подтверждает одну запись через разрешённый API приложения. В данных остаётся шесть неподтверждённых пропусков. После повторного открытия обзора счётчик «Без подтверждения» должен уменьшиться на один без нового входа в систему.

### `test_bp_36_attendance_boundaries`

Сначала тест легитимно очищает дневные отметки в `localStorage`. На обзоре метрика посещаемости должна показывать 0 %, не содержать `NaN` и не ломать страницу. Затем тест восстанавливает начальные данные и подготавливает 28 отметок «Был» за день. Метрика должна показать 100 % и подпись «28 из 28 присутствуют».
