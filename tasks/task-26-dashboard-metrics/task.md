# Дашборд: метрики класса

## Сайт

«Кабинет классного руководителя» — одностраничное приложение для классного
руководителя 7Б класса. После входа классный руководитель попадает на экран
«Обзор класса 7Б». На дашборде отображаются показатели класса, которые
рассчитываются из актуальных записей журнала и не сохраняются отдельно.

Метрика «Посещаемость сегодня» учитывает все внесённые отметки за все уроки
текущего дня. Средний балл класса показан за I четверть и сопровождается
сравнением с прошлой неделей. Метрика «Без подтверждения» содержит только
пропуски со статусом «Н (без)»; ссылка под ней открывает посещаемость с
фильтром неподтверждённых пропусков.

Все данные хранятся в `localStorage` браузера. Демонстрационная база создаётся
заново после очистки `localStorage`.

## Начальные данные

- после входа классный руководитель открывает «Обзор класса 7Б»;
- за I четверть средний балл класса — 4,2, подпись дашборда показывает
  «+0,1 к прошлой неделе»;
- за I четверть есть 5 неподтверждённых пропусков со статусом «Н (без)»;
- в день без внесённых отметок посещаемость отображается как 0 %, без `NaN` и
  ошибки страницы;
- в день, когда все 28 учеников отмечены «Был», посещаемость равна 100 %.

## Что проверить

1. `test_bp_01_teacher_default_screen` — после входа под классным руководителем
   открывается «Обзор класса 7Б», а не первый иной пункт меню.
2. `test_bp_02_dashboard_attendance` — посещаемость за день рассчитывается по
   отметкам всех уроков дня: при 55 отметках «Был» из 56 показано 98,2 %, а
   подпись содержит число учеников класса.
3. `test_bp_03_dashboard_average_delta` — средний балл класса сопровождается
   подписью «+0,1 к прошлой неделе», а не сравнением с началом периода.
4. `test_bp_04_unconfirmed_metric` — метрика «Без подтверждения» равна 5 и
   ссылка «К журналу →» ведёт на посещаемость с фильтром неподтверждённых
   пропусков.
5. `test_bp_05_metrics_recalculated` — после подтверждения одного пропуска
   дашборд пересчитывается: число неподтверждённых пропусков I четверти уменьшается с
   5 до 4 без повторного входа.
6. `test_bp_36_attendance_boundaries` — отсутствие отметок не даёт `NaN`, а
   полный день из 28 отметок «Был» показывает 100 %.
