# Родители: связи и основной контакт

## Назначение

Раздел «Родители» хранит карточку человека отдельно от его связей с учениками. Классный руководитель может связать существующего родителя с учеником, снять связь и удалить только несвязанную карточку. Для каждого ученика допускается ровно один основной контакт. Изменение телефона меняет существующую карточку человека, а не создаёт новую.

Данные стенда хранятся в `localStorage` и восстанавливаются после очистки. Демонстрационная дата — 28.10.2024.

## Исходные данные

- Орлова Надежда Павловна не связана с учениками.
- Карточка родителя `pr-21` используется для связи с учеником `st-16` в роли «Опекун».
- У ученика `st-16` до назначения нового основного контакта уже есть основная связь; после назначения основной остаётся только новая связь.
- Родитель `pr-23` связан с учеником, поэтому удалять его нельзя.
- Орлова Надежда Павловна (`pr-21`) не имеет связей и может быть удалена из списка.

## Что нужно реализовать

Реализуйте единообразное хранение карточек родителей и связей с учениками: обновление без дублей, связывание существующей карточки, единственный основной контакт, безопасное снятие связи и правила удаления.

## Проверяемые сценарии

1. `test_pr_07_unique_phone` — у родителя `pr-23` телефон меняется на `+7 999 123-45-69`. Число карточек родителей не увеличивается, а в базе ровно одна карточка с новым телефоном.
2. `test_pr_08_link_existing_parent` — существующая карточка `pr-21` связывается с учеником `st-16` в роли «Опекун» без признака основного контакта. Число карточек родителей не меняется; появляется связь именно между этими идентификаторами.
3. `test_pr_09_single_primary` — при связывании `pr-21` с `st-16` как основного контакта у этого ученика после операции остаётся ровно одна основная связь, и она принадлежит `pr-21`.
4. `test_pr_10_unlink_keeps_card` — после создания связи `pr-21` с `st-16` её снимают. Связь исчезает, но карточка `pr-21` остаётся в базе; снятие связи не должно удалять карточку человека.
5. `test_pr_11_delete_linked_forbidden` — попытка удалить связанного родителя `pr-23` отклоняется с текстом «Сначала снимите связь». Карточка остаётся в базе.
6. `test_pr_12_delete_unlinked` — классный руководитель находит «Орлова Надежда Павловна», открывает меню строки и удаляет её. Строка сразу исчезает из отфильтрованного списка, а карточка `pr-21` отсутствует в данных.

## Особенности автоматической проверки

Сценарии 1–5 используют `crmApi`, чтобы точно подготовить связи и проверить инварианты хранилища. Это легитимная подготовка для проверки бизнес-правил; пользовательский интерфейс дополнительно проверяется в сценарии удаления. Не привязывайте реализацию к вызовам теста.
