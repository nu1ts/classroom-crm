# Список учеников: сортировка, поиск, фильтр и пагинация

## Сайт

«Кабинет классного руководителя» — одностраничное приложение для классного
руководителя 7Б класса. Раздел «Ученики» показывает список класса с колонками
«Ученик», «Статус», «Средний балл», «Пропуски», «Родитель для связи» и
«Действия». Список по умолчанию отсортирован по фамилии, разбит на страницы
по 10 учеников, поддерживает поиск по фамилии и фильтр «С пропусками».
В строке ученика можно открыть краткую сводку.

Все данные хранятся в `localStorage` браузера. Поиск не зависит от регистра,
фильтр и поиск применяются одновременно, пустой результат показывает блок
«Ничего не найдено» со сбросом фильтров. Показатели в списке и в сводке
ученика считаются одинаково.

## Подсказка

Список перерисовывается без перезагрузки страницы: поиск вводится в поле
`#input-search-student-list`, фильтр включается кнопкой
`#btn-filter-absences-toggle`, строки таблицы имеют класс `student-row-item`
и атрибут `data-student-id`. Счётчик находится в
`#students-counter-label`, пагинация — в кнопках `.btn-pagination-page`.

1. `test_ov_01_students_list_order` — в списке 28 учеников и шесть колонок;
   по умолчанию первая строка — Александров Егор; у Петровой Анны в колонке

2. `test_ov_02_list_matches_summary` — у Петровой Анны в списке и в сводке
   совпадают значения 4,5 и «4 из 40»; у Сидорова Никиты — 3,1 и

3. `test_ov_03_search_case_insensitive` — поиск «сидор» строчными буквами
   находит ровно одну строку Сидорова и счётчик «Показано 1 из 28»; после

   с ненулевыми пропусками и исключает Александрова, Николаеву и Романова;
   после отключения фильтра снова 28 учеников.
5. `test_ov_06_search_and_filter_combined` — при включённом фильтре поиск
   «Петров» даёт одну строку Петровой, а поиск «фыва» — пустой результат
   с текстом «Ничего не найдено», счётчиком «из 0» и кнопкой сброса;
   сброс возвращает полный список без фильтра.
6. `test_ov_08_pagination` — три страницы по 10, 10 и 8 учеников; счётчик
   меняется с «Показано 1–10 из 28» на «Показано 21–28 из 28»; строки между
   страницами не повторяются и не пропадают.
