# Отчёт по классу

## Сайт

«Кабинет классного руководителя» — одностраничное приложение школы. В разделе
«Аналитика» классный руководитель формирует отчёт по успеваемости и
посещаемости своего класса. Отчёт строится по актуальным данным журнала в
момент открытия, его можно распечатать или сохранить из окна просмотра.

Отчёт учитывает выбранный период. Границы периода включаются: для I четверти
это 02.09–25.10.2024, для октября — 01.10–25.10.2024. Классный руководитель
работает только с назначенным ему классом; данные других классов ему не
доступны, в том числе по прямой ссылке.

Все данные хранятся в `localStorage` браузера. Очистка `localStorage` создаёт
демонстрационную базу заново. Демонстрационная дата — 28.10.2024.

## Данные для входа

| Роль | Логин | Пароль |
| --- | --- | --- |
| Классный руководитель 7Б | `smirnova@school.ru` | `Test#2024` |
| Классный руководитель 8А | `ivanova@school.ru` | `Test#2024` |

## Начальные данные

- для 7Б доступна аналитика за I четверть, октябрь и неделю 21–25.10.2024;
- отчёт содержит средний балл, посещаемость, число неподтверждённых пропусков,
  число учеников зоны риска, динамику пропусков и средние по предметам;
- в заголовке отчёта выводится полный выбранный период;
- повторное формирование без изменения данных даёт те же значения, а после
  изменения журнала показатели пересчитываются;
- занятия и отметки за 25.10.2024 входят в отчёт за октябрь и за неделю
  21–25.10.2024;
- классный руководитель 7Б не может открыть аналитику 8А по адресу
  `/analytics?classId=class-8a`.

## Что проверить

1. `test_bp_31_report_period` — после выбора I четверти и формирования отчёта
   в нём видны показатели успеваемости и посещаемости, заголовок периода
   «I четверть (02.09–25.10.2024)» и кнопка «Печать / Экспорт».
2. `test_bp_32_report_not_cached` — два отчёта без изменения журнала имеют
   одинаковые показатели; после добавления оценки в журнал показатель среднего
   балла в новом отчёте меняется, а отдельный сохранённый отчёт в базе не
   создаётся.
3. `test_bp_33_report_period_boundaries` — отчёт за неделю 21–25.10.2024
   учитывает отметки занятия, добавленного на 25.10.2024: его посещаемость
   совпадает с расчётом по всем отметкам включительно по последний день.
4. `test_bp_35_teacher_own_class` — классный руководитель 7Б при прямом
   переходе к аналитике 8А получает сообщение «Доступ ограничен»; отчёт и
   показатели чужого класса не отображаются.
