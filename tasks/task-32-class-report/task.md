# Отчёт по классу

## Назначение

Классный руководитель формирует в разделе «Аналитика» отчёт по успеваемости и посещаемости своего класса. Отчёт открывается на `/analytics/` после выбора периода и действия формирования; он содержит средний балл, посещаемость, неподтверждённые пропуски и число учеников зоны риска. Отчёт строится из текущих данных журнала, не сохраняется отдельным кэшем и доступен только для своего класса.

Границы периода включительны: I четверть — 02.09–25.10.2024, неделя для сценария — 21–25.10.2024. Демонстрационная дата — 28.10.2024. Очистка `localStorage` восстанавливает исходную базу.

## Учётные записи

| Роль | Логин | Пароль |
| --- | --- | --- |
| Классный руководитель 7Б | `smirnova@school.ru` | `Test#2024` |
| Классный руководитель 8А | `ivanova@school.ru` | `Test#2024` |

## Исходные данные

- Для 7Б доступны отчёты за I четверть, октябрь и неделю 21–25.10.2024.
- В отчёте есть кнопка «Печать / Экспорт».
- Классный руководитель 7Б не имеет права видеть аналитику 8А по адресу `/analytics?classId=class-8a`.

## Проверяемые сценарии

### `test_bp_31_report_period`

Войти классным руководителем 7Б, открыть `/analytics/?periodId=q1_2024` и сформировать отчёт. В нём должен быть заголовок «Отчёт по успеваемости и посещаемости 7Б класса» и период «I четверть (02.09–25.10.2024)». Значения среднего балла, посещаемости, неподтверждённых пропусков и зоны риска не должны быть пустыми. Должна отображаться кнопка «Печать / Экспорт».

### `test_bp_32_report_not_cached`

Сформировать отчёт за I четверть и запомнить средний балл. Закрыть и снова сформировать отчёт без изменения журнала: значение должно совпасть. Затем тест легитимно добавляет в журнал оценки, изменяющие отображаемый средний балл, обновляет страницу и формирует отчёт снова. Средний балл должен измениться, а в `localStorage` не должна появиться коллекция сохранённых `classReports`.

### `test_bp_33_report_period_boundaries`

Тест легитимно подготавливает для недели 21–25.10.2024 две отметки урока 25.10.2024: одну «Был» и одну «Отсутствовал». После формирования отчёта за `week_21_25_10` метрика посещаемости должна быть ровно 50 %. Это подтверждает, что последний день выбранного периода включён в расчёт.

### `test_bp_35_teacher_own_class`

Войти классным руководителем 7Б и открыть прямой адрес `/analytics?classId=class-8a`. Должно быть показано сообщение «Доступ ограничен». Раздел аналитики и сформированный отчёт чужого класса отображаться не должны.
