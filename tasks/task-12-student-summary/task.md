# Сводка ученика

## Назначение

Реализуйте подробную сводку ученика: персональные показатели, предметные результаты, историю пропусков, контакты с родителями и приватные заметки. Учитывайте ролевые ограничения для классного руководителя, родителя и ученика.

| Роль | Учётная запись |
| --- | --- |
| Классный руководитель Смирнова М. В. | `smirnova@school.ru` / `Test#2024` |
| Родитель Петров С. В. | `petrov@mail.ru` / `Test#2024` |
| Ученица Петрова Анна | `petrova.a@school.ru` / `Test#2024` |

Карточка открывается на `/student/?id=…`; Петрова Анна имеет идентификатор `st-23`. Родитель работает через `/child/`. База восстанавливается после очистки `localStorage`.

## Исходные данные и требования

У Петровой Анны: средний балл 4,5; 4 дня и 4 урока пропусков в I четверти, все по болезни; математика 3,2, русский язык 4,6, «Разговоры о важном» без оценок. Предметы ниже 3,5 выделяются красным, с баллом от 4,5 — зелёным. В сводке есть пропуски 13.09, 26.09, 24.10 и 25.10. Записи за 24.10 и 25.10 — отдельные неподтверждённые пропуски: для каждой доступно своё действие «Подтвердить причину». Медсправка, переданная 25.10, сама по себе не подтверждает запись: подтверждение оформляется отдельно.

Контакты отсортированы от новых к старым: звонок матери 24.10.2024 в 15:20, личная беседа 15.10.2024 в 18:45. У ученицы изначально нет заметок; добавленная заметка классного руководителя приватна и сохраняется в `localStorage` после перезагрузки. Родитель видит показатели только своего ребёнка без блока «Заметки классрука». Котова Дарья из 9В (`ext-Котова Дарья`) доступна классному руководителю только для просмотра. Ученик не открывает чужую карточку, а родитель не открывает `/student/` даже для своего ребёнка: в обоих случаях «Доступ ограничен» без карточки.

4. `test_ov_15_notes_persisted` — добавьте «Приватная заметка классрука для проверки». Она сразу видна в разделе заметок с меткой «Приватно (только для классрука)», записана в браузерную базу и остаётся после перезагрузки.
