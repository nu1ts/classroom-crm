# Список внимания: обход и отчёт

## Назначение

Классный руководитель 7Б обрабатывает учеников из списка внимания на маршруте `/overview/`: добавляет педагогические заметки, просматривает сводку ученика и переходит к отчёту. Данные приложения хранятся в `localStorage`; демонстрационная дата — 28.10.2024, а очистка хранилища возвращает исходную базу.

В сводке ученика на `/student/?id=<идентификатор>&period=q1_2024` доступны успеваемость, пропуски, контакты родителей и история общения. Журнал оценок в сводке должен показывать все предметы ученика за выбранный период. Контакты родителей упорядочиваются так, чтобы основной контакт был первым.

## Проверяемые сценарии

### `test_bp_20_empty_attention_report`

Тест легитимно заменяет все отметки отсутствия на присутствие и повышает оценки ниже 4 до 4, чтобы в 7Б не осталось учеников в зоне риска. На `/overview/` должен появиться текст «Учеников в зоне риска за данный период нет» и ссылка «К отчёту» на `/analytics/`. Переход по ссылке должен открыть аналитику.

### `test_bp_21_attention_cycle`

Открыть обзор с исходными данными, где в списке внимания не менее трёх карточек. Для каждой исходной карточки открыть форму добавления заметки, сохранить заметку «Обработан: <ФИО>» и убедиться, что в соответствующей карточке появился статус «Обработан». После обработки всех исходных учеников должно появиться сообщение «Все N учеников списка внимания обработаны!» и ссылка «К отчёту →». Ни одна карточка не должна остаться без статуса обработки.

### `test_bp_22_student_journal_all_subjects`

Открыть сводку Петровой Анны Сергеевны (`st-23`) за I четверть. На странице должны быть её ФИО, «Средний балл», «Пропусков всего», «Контакты родителей» и «История общения с родителями». После открытия блока «Журнал оценок» в нём должны быть названия всех предметов, по которым у ученицы есть оценки в I четверти, и таких предметов должно быть не меньше двух.

### `test_bp_23_contacts_by_student`

Тест легитимно добавляет в `localStorage` два контакта одного родителя: контакт «Контакт по Петровой» для Петровой Анны (`st-23`) и «Чужой контакт по Сидорову» для другого ученика (`st-01`). В сводке Петровой история общения должна содержать только «Контакт по Петровой»; контакт другого ребёнка показывать нельзя.

### `test_bp_24_primary_contact_first`

Открыть сводку Петровой Анны. В блоке «Контакты родителей» первым должен быть Петров Сергей Викторович, телефон `+7 999 123-45-63`, с пометкой «Основной контакт».
