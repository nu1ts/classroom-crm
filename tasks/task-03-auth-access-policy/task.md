# Политика паролей, блокировки и сброса

## Сайт

«Кабинет классного руководителя» — одностраничное приложение с входом по
логину и паролю. Роль пользователя определяет доступные разделы: классный
руководитель видит аналитику и список учеников, родитель — только карточку
ребёнка, расписание и объявления. При смене пользователя в одном браузере
доступ должен пересчитываться по новой учётной записи.

Администратор управляет учётными записями в разделе «Учётные записи»: может
заблокировать и разблокировать пользователя, а также сбросить его пароль.
Сброс выдаёт временный пароль, который требуется сменить при первом входе.
Самостоятельного восстановления пароля на экране входа нет.

Новый пароль должен содержать не менее 8 символов, буквы в обоих регистрах и
хотя бы одну цифру. Поле повтора должно совпадать с новым паролем.

## Начальные данные

- все учётные записи активны, блокировок и счётчиков неудачных попыток нет;
- демонстрационная база создаётся заново после очистки `localStorage`;
- в 7Б классе 28 учеников; аналитика класса и список учеников доступны
  классному руководителю;
- порог автоматической блокировки — 5 неудачных попыток входа подряд;
- сброс пароля администратором выдаёт временный пароль вида `Temp#000024`;
- после смены временного пароля прежний временный пароль больше не действует.

## Что проверить

1. `test_auth_09_switch_user_role_context` — после выхода из кабинета
   классного руководителя и входа под родителем доступны только «Ребёнок»,
   «Расписание» и «Объявления»; прямые адреса аналитики и списка учеников, а
   также кнопка «назад» не показывают данные классного руководителя, сессия
   прежнего пользователя завершена.
2. `test_auth_12_new_password_policy` — пароль из 7 символов и пароль из 8
   строчных букв без цифры отклоняются с указанием требования; пароль ровно
   из 8 символов с буквами обоих регистров и цифрой принимается; при
   несовпадении повтора показывается «Пароли не совпадают», и пароль не
   меняется.
3. `test_auth_14_blocked_account_rejected` — после блокировки учётной записи
   администратором вход с верным паролем отклоняется с сообщением о
   блокировке; после разблокировки тот же пароль открывает кабинет, роль и
   данные ученика сохраняются.
4. `test_auth_15_self_reset_unavailable` — ссылка «Забыли пароль?» открывает
   пояснение с контактами администратора и не содержит формы самостоятельного
   сброса; после сброса пароля администратором вход с временным паролем требует
   его смены, а после смены временный пароль перестаёт работать.
