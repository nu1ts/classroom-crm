# Обзор класса: список и фильтры

## Назначение

Реализуйте на странице «Ученики» список 7Б с поиском, фильтром пропусков, статусом, признаком риска и переходом в сводку. Список должен согласованно использовать данные успеваемости, посещаемости и основного контакта.

## Роль, учётная запись и маршрут

Работает классный руководитель 7Б Смирнова М. В.: `smirnova@school.ru` / `Test#2024`. После входа откройте раздел «Ученики» на маршруте `/students/`. Демонстрационная база восстанавливается после очистки `localStorage`.

## Исходные данные и требования

В 7Б 28 учеников. На странице выводятся колонки «ФИО УЧЕНИКА», «СТАТУС», «СРЕДНИЙ БАЛЛ», «ПРОПУСКИ», «РОДИТЕЛЬ ДЛЯ СВЯЗИ», «ДЕЙСТВИЯ»; исходная сортировка — по фамилии, первая строка — Александров Егор Алексеевич. У всех статус «Активен». Отдельный бейдж «В зоне риска» есть у Сидорова, Морозова, Петровой, Волковой и Котова.

У Петровой Анны средний балл 4,5, 4 из 40 пропусков, основной контакт — Петров Сергей Викторович, +7 999 123-45-63; у Сидорова Никиты — 3,1 и 12 из 40. Пропуски есть у 25 учеников; у Александрова, Николаевой и Романова их нет. Поиск не зависит от регистра, фильтр «С пропусками» и поиск применяются одновременно. Счётчик всегда отражает размер класса, а не размер результата: например, «Показано 1–10 из 28 учеников 7Б класса»; при пустой выборке — «Показано 0–0 из 28 учеников 7Б класса». В пустом состоянии показываются «Ничего не найдено» и сброс фильтров.

## Проверяемые сценарии

1. `test_ov_01_default_list` — убедитесь в 28 учениках и шести колонках; первая строка — Александров. По поиску «Петрова» строка Анны содержит отца и его телефон, но не мать. После штатного зачисления «Абрамов Тимур» счётчик равен 29, личное дело нового ученика — 29, а первой алфавитной строкой становится Абрамов.
2. `test_ov_02_list_matches_summary` — в списке и в открываемой из него сводке Петровой совпадают 4,5 и «4 из 40», у Сидорова — 3,1 и «12 из 40».
3. `test_ov_03_search_case_insensitive` — строковый поиск «сидор» находит только Сидорова Никиту Артёмовича и «Показано 1 из 28»; очистка поиска восстанавливает список из 28.
4. `test_ov_04_absences_filter` — включённый фильтр «С пропусками» исключает Александрова, Николаеву и Романова; счётчик остаётся «Показано 1–10 из 28 учеников 7Б класса». Выключение возвращает полный список.
5. `test_ov_05_status_and_risk_badge` — у всех 28 строк в колонке статуса только «Активен»; ровно пять перечисленных учеников имеют отдельный бейдж риска, который не попадает в колонку статуса.
6. `test_ov_06_search_with_filter` — при включённом фильтре поиск «Петров» оставляет одну Петрову и счётчик «Показано 1 из 28»; очистка поиска не выключает фильтр.
7. `test_ov_07_empty_result_state` — при фильтре пропусков поиск «александров» оставляет пустую таблицу с «Ничего не найдено», счётчиком «Показано 0–0 из 28 учеников 7Б класса» и кнопкой сброса. Сброс очищает поиск, выключает фильтр и возвращает полный список.
