# Обзор класса: список и фильтры

## Сайт

«Кабинет классного руководителя» — одностраничное приложение для классного
руководителя 7Б класса. Раздел «Ученики» показывает список класса с колонками
«Ученик», «Статус», «Средний балл», «Пропуски», «Родитель для связи» и
«Действия».

Список по умолчанию отсортирован по фамилии и показывает по 10 учеников на
странице. Поиск по фамилии не зависит от регистра, фильтр «С пропусками»
оставляет только учеников с пропусками, поиск и фильтр применяются
одновременно. Пустой результат показывает блок «Ничего не найдено» со сбросом
фильтров. В строке ученика можно открыть краткую сводку.

Все данные хранятся в `localStorage` браузера. Показатели в списке и в сводке
ученика считаются одинаково.

## Начальные данные

- в 7Б классе 28 учеников; по умолчанию список отсортирован по фамилии:
  первая строка — Александров Егор, последняя — Якушева Кристина;
- у всех учеников в колонке «Статус» стоит «Активен»; признак «В зоне риска»
  показывается отдельным бейджем рядом с ФИО у пяти учеников: Сидорова
  Никиты, Морозова Артёма, Петровой Анны, Волковой Софии и Котова Максима;
- у Петровой Анны средний балл 4,5 и 4 пропуска из 40; основной контакт —
  отец Петров Сергей Викторович (+7 999 123-45-63), хотя в сводке есть и
  мать Петрова Елена Игоревна;
- у Сидорова Никиты средний балл 3,1 и 12 пропусков из 40;
- пропуски есть у 25 учеников; без пропусков — Александров Егор,
  Николаева Виктория и Романов Илья;
- поиск «сидор» находит одну строку, счётчик показывает
  «Показано 1 из 28 учеников 7Б класса»;
- фильтр «С пропусками» и поиск «Петров» вместе дают одну строку —
  Петрову Анну со счётчиком «1 из 28»;
- фильтр «С пропусками» вместе с поиском «александров» не находит никого:
  список пуст, счётчик показывает «0 из 28», доступна кнопка сброса фильтров;
- зачисление нового ученика с фамилией «Абрамов» добавляет его в конец
  списка учеников, но в списке он показывается по алфавиту — раньше
  Александрова, и личное дело нового ученика — 29;
- демонстрационная база создаётся заново после очистки `localStorage`.

## Что проверить

1. `test_ov_01_default_list` — в списке 28 учеников и шесть колонок; по
   умолчанию первая строка — Александров Егор; у Петровой Анны в колонке
   «Родитель для связи» указан основной контакт Петров Сергей Викторович
   с телефоном +7 999 123-45-63, а не мать; после зачисления ученика
   «Абрамов Тимур» список содержит 29 учеников и начинается с «Абрамов».
2. `test_ov_02_list_matches_summary` — у Петровой Анны в списке и в сводке
   балл 4,5 и «4 из 40»; у Сидорова Никиты в списке и в сводке 3,1 и
   «12 из 40».
3. `test_ov_03_search_case_insensitive` — поиск «сидор» строчными буквами
   находит ровно одну строку Сидорова и счётчик «Показано 1 из 28»; после
   очистки поиска список снова показывает 28 учеников.
4. `test_ov_04_absences_filter` — фильтр «С пропусками» оставляет 25 учеников
   с ненулевыми пропусками и исключает Александрова, Николаеву и Романова;
   после отключения фильтра снова 28 учеников.
5. `test_ov_05_status_and_risk_badge` — во всех 28 строках колонка «Статус»
   содержит только «Активен»; бейдж «В зоне риска» стоит ровно у пяти учеников
   из начальных данных и не попадает в колонку «Статус».
6. `test_ov_06_search_with_filter` — при включённом фильтре «С пропусками»
   поиск «Петров» даёт ровно одну строку Петровой и счётчик «1 из 28»;
   после очистки поиска фильтр остаётся включённым.
7. `test_ov_07_empty_result_state` — при включённом фильтре «С пропусками»
   поиск «александров» даёт пустой список с сообщением «Ничего не найдено»,
   счётчиком «0 из 28» и кнопкой сброса; после сброса снова видны 28 учеников,
   поиск очищен, фильтр выключен.
