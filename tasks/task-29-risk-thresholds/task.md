# Зона риска: пороги и пересчёт

## Сайт

«Кабинет классного руководителя» — одностраничное приложение для классного
руководителя 7Б класса. На странице «Обзор класса» расположен список внимания:
в него попадают ученики с пропусками более 20 % уроков за период или со средним
баллом ниже 3,5. Список должен строиться из актуальных данных при каждом
открытии страницы.

Записи списка внимания упорядочиваются по убыванию доли пропусков, а при равной
доле — по возрастанию среднего балла. После обработки всех учеников классный
руководитель может перейти к формированию отчёта. Это правило действует и для
списка из одного ученика.

Все данные хранятся в `localStorage` браузера. Демонстрационная база создаётся
заново после очистки `localStorage`.

## Что проверить

1. `test_bp_16_absence_threshold_20` — ученик с 8 пропусками из 40 уроков
   (ровно 20,0 %) не попадает в список внимания: порог задан как «более 20 %».
2. `test_bp_17_grade_threshold_3_5` — ученик со средним баллом ровно 3,5 не
   попадает в список внимания: порог задан как «ниже 3,5».
3. `test_bp_18_risk_not_cached` — после исправления данных ученик, который
   перестал соответствовать критериям, исчезает из списка без повторного входа
   в систему.
4. `test_bp_19_risk_order` — список внимания содержит учеников с долями
   пропусков 30,0 %, 22,5 % и 22,5 % в порядке убывания.
5. `test_bp_37_single_student_report` — после обработки единственного ученика
   из списка внимания становится доступен переход к формированию отчёта.
