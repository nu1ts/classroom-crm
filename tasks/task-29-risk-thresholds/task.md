# Зона риска: пороги и пересчёт

## Назначение

На маршруте `/overview/` классный руководитель 7Б работает со «Списком внимания». Ученик попадает в него при доле пропусков строго больше 20 % или при среднем балле строго ниже 3,5. Список пересчитывается из текущих данных при каждом открытии страницы. Карточки упорядочены по убыванию доли пропусков; при равной доле учитывается средний балл. После обработки всех карточек доступен переход «К отчёту».

Демонстрационная база хранится в `localStorage` и восстанавливается после его очистки. Демонстрационная дата — 28.10.2024.

Тест легитимно подготавливает для Морозова Артёма Андреевича (`st-09`) нулевое число пропусков и оценки 3 и 4, то есть средний балл ровно 3,5. На обзоре ученик не должен попасть в список внимания.

### `test_bp_18_risk_not_cached`

Тест подготавливает для ученика `st-17` 12 пропусков из 40 и оценки не ниже 4. На обзоре этот ученик сначала должен быть в списке внимания. Затем тест меняет его данные на семь пропусков из 40. После повторного открытия `/overview/` ученик с долей 17,5 % не должен остаться в списке без повторного входа.

### `test_bp_19_risk_order`

Тест создаёт контролируемый набор: у одного ученика 12 пропусков из 40 (30,0 %), у двух следующих — по девять пропусков из 40 (22,5 %), при оценках не ниже 4. В списке внимания карточки этих трёх учеников должны идти в порядке 30,0 %, 22,5 %, 22,5 %; ученики с одинаковой долей не должны оказаться раньше карточки с большей долей.

### `test_bp_37_single_student_report`

Тест легитимно подготавливает в 7Б только одного ученика в зоне риска. На `/overview/` должна остаться одна карточка. Добавить к ней заметку через форму «Добавить заметку». После сохранения появляется сообщение «Все 1 учеников списка внимания обработаны» и доступная ссылка «К отчёту» на `/analytics/`.
